## 1. 知识库 - 列表/选择

### 1.1 功能概述

知识库模块首页：左侧展示知识库列表，右侧展示所选知识库的文档列表；未选择时显示引导空态。

### 1.2 路由与入口

- 路由：`/knowledge`；侧边栏“知识库”。

### 1.3 页面布局

| 区域 | 说明 |
| --- | --- |
| 左侧列表 | 宽度约 240px：标题“知识库” + “创建知识库”按钮 + 知识库条目列表 |
| 右侧主区 | 所选知识库的文档列表（见 §3）；未选择时显示空态 |

### 1.4 元素明细

| 元素 | 说明 |
| --- | --- |
| 创建按钮 | 列表顶部主按钮“+ 创建知识库”，点击弹窗（见 §2） |
| 知识库条目 | 图标（文件夹）+ 名称 + 文档数（建议）；hover 高亮并显示编辑/删除操作；点击选中 |
| 选中态 | 主色/浅紫底 + 主色文字 + 左侧指示条 |
| 右侧空态 | 图标 + “请选择知识库” + “选择左侧知识库查看文档” |
| 删除知识库 | 二次确认弹窗：“删除后将同时删除其中所有文档与切片，且不可恢复”；确认后删除并刷新 |

### 1.5 状态设计

- 加载中：列表骨架屏；
- 无知识库：空态 + “立即创建”按钮；
- 删除成功/失败：Toast 反馈。

### 1.6 验收要点

- 创建后新知识库立即出现在列表并自动选中；
- 删除知识库二次确认、删除后右侧主区回到空态；
- 列表刷新、选中切换正确。

## 2. 创建知识库弹窗

### 2.1 触发入口

知识库页“创建知识库”按钮。

### 2.2 弹窗规格

| 元素 | 说明 |
| --- | --- |
| 弹窗 | 宽约 480px；标题“创建知识库”；右上角 ×；遮罩半透明；支持点击遮罩/ESC 关闭（建议） |
| 名称输入框 | 必填；占位“例如：知识库”；长度 ≤ 50 字；失焦/提交时校验唯一性 |
| 描述输入框 | 多行；占位“描述知识库的功能”；长度 ≤ 200 字；显示字数统计 |
| 取消按钮 | 关闭弹窗，不保存，不校验 |
| 确定按钮 | 主色；提交中禁用并显示 loading；校验通过后提交 |

### 2.3 校验规则

| 场景 | 提示 |
| --- | --- |
| 名称为空 | “请输入知识库名称” |
| 名称超长 | “名称不超过 50 字” |
| 名称重复 | “该名称已存在” |
| 描述超长 | “描述不超过 200 字” |

### 2.4 状态设计

- 提交成功：关闭弹窗 + Toast“创建成功” + 新知识库选中；
- 提交失败：弹窗内红字错误提示，保留已填内容，不关闭。

### 2.5 验收要点

- 必填、长度、唯一性校验全部生效；
- 关闭方式（×/遮罩/ESC）均可用；提交中防重复提交。

## 3. 知识库 - 文档列表

### 3.1 功能概述

展示所选知识库内全部文档，支持上传、搜索、查看详情与删除。

### 3.2 路由与入口

- 路由：`/knowledge/:kbId`；从知识库列表选中进入。

### 3.3 页面布局

| 区域 | 说明 |
| --- | --- |
| 工具行 | 返回按钮（←）+ 知识库名称/描述 + 搜索框 + 上传按钮 |
| 表格区 | 文件列表表格 + 分页 |

### 3.4 元素明细

**工具行**

| 元素 | 说明 |
| --- | --- |
| 返回 | 返回知识库列表 |
| 搜索框 | 占位“搜索文件名”；输入防抖（300ms）实时过滤；带搜索图标与清空按钮 |
| 上传按钮 | 主按钮“上传文件”/上传图标；支持点击选择与拖拽上传（拖拽区域高亮） |

**文件表格**

| 列 | 说明 |
| --- | --- |
| 文件名 | 文件类型图标 + 名称；过长省略（省略号 + title 完整名） |
| 类型 | 扩展名标签（如 xlsx） |
| 状态 | 标签：已完成（绿）/ 解析中（蓝，带转圈图标）/ 失败（红，可“重新解析”） |
| Chunk 数量 | 数字，如 6；点击可进入详情（建议） |
| 操作 | “查看详情”（主色文字按钮）、删除（红字）；删除需二次确认并提示级联删除 |

**分页**

- 默认每页 10 条；显示总数；支持页码切换。

**空态**

- 无文件：“暂无文档，请上传文件” + 上传按钮；
- 搜索无结果：“未找到匹配的文件” + 清空搜索按钮。

### 3.5 上传交互

1. 选择文件后立即上传，显示进度条（顶部或卡片内）；
2. 支持一次多选；同名校验（覆盖/跳过提示，建议）；
3. 上传完成自动刷新列表；解析状态异步更新（解析中 → 已完成/失败）；
4. （变更）支持格式：`.xlsx/.csv/.md/.txt/.pdf/.docx`（正式支持，原为建议项），单文件 ≤ 20MB；
5. （新增）普通文本分块参数：按固定长度 500 字、重叠 50 字切分（已确认），标题/段落结构优先；参数在“系统设置 → 数据管理”中可调。

### 3.6 验收要点

- 上传后状态正确流转；解析失败可重试；
- 搜索防抖生效、可清空；分页正确；
- 删除二次确认且生效后列表与检索结果同步移除。

## 4. 文件详情 / Chunk 管理

### 4.1 功能概述

查看文档解析出的 Chunk 列表（问题/答案/元信息），支持编辑与删除，保证知识库内容可维护。

### 4.2 路由与入口

- 路由：`/knowledge/:kbId/documents/:docId`；文件列表“查看详情”进入。

### 4.3 页面布局

| 区域 | 说明 |
| --- | --- |
| 顶部 | 面包屑：知识库名 / 文件名；返回按钮 |
| 列表区 | Chunk 卡片列表，每张卡片一个“问题-答案”对 |

### 4.4 元素明细

| 元素 | 说明 |
| --- | --- |
| Chunk 卡片 | 序号（Chunk 1…）+ 问题标题 + 答案全文 + 元信息行（页码/行号、字数、标签）+ 操作（编辑/删除） |
| 编辑弹窗 | 问题输入框 + 答案多行文本；保存/取消；保存后提示“已更新，正在重新向量化”（异步） |
| 删除 | 二次确认；删除后列表即时移除 |
| 新增 Chunk（变更） | 列表底部“+ 添加 Chunk”（原为建议，转为正式）；弹窗填写问题/答案/标签（可选）/页码行号（可选） |
| 重新解析（建议） | 顶部按钮，触发文档整体重新切片 |
| 空态 | “暂无 Chunk，请重新解析文档或手动添加” |

### 4.5 校验规则

- 问题必填、≤ 200 字；答案必填、≤ 2000 字（建议）；
- （新增）标签可选，单个 ≤ 20 字，最多 10 个，多个用英文逗号分隔；
- 编辑保存中禁用按钮防重复提交。

### 4.6 FAQ 模板示例数据（导入后预期结果）

> （变更）FAQ 模板列结构：`问题 | 答案 | 分类（可选） | 标签（可选，多个用英文逗号分隔）`。

| Chunk | 问题 | 答案（摘要） | 标签 |
| --- | --- | --- | --- |
| 1 | 商品发货后几天可以退货？ | 自签收之日起 7 天内，商品完好、配件齐全、不影响二次销售可无理由退货 | 退货 |
| 2 | 退款审核多久到账？ | 审核通过后 3 个工作日内到账，视银行处理时间为准 | 退款 |
| 3 | 软件激活后还能卸载吗？ | 软件/会员/票证等虚拟商品已激活使用一般不支持无理由退货 | 退款/虚拟商品 |
| 4 | 质量问题退货运费谁承担？ | 确认质量问题，商家承担来回运费 | 退货/运费 |
| 5 | 我要投诉该怎么做？ | 通过在线/人工客服建立工单并转人工处理 | 投诉 |
| 6 | 订单物流在哪里查看？ | 提供订单号后查询物流公司、运单号、当前状态与物流轨迹 | 物流 |

### 4.7 验收要点

- Chunk 内容与导入模板逐条一致（原型 6 条）；
- 编辑/删除后重新检索结果同步变化；
- 面包屑与返回路径正确；
- （新增）标签展示/编辑生效，检索测试可按标签过滤（见 `05_检索测试.md` §4.1）；
- （变更）手动新增 Chunk 后立即出现在列表并可检索。
