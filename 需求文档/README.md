# 需求文档目录（按模块拆分）

> 来源：`需求功能报告.md` v1.1（2026-08-10）
> 用途：将完整需求文档按模块拆分为独立文件，方便 agent 按模块领取任务。

## 使用方式（给 agent 的读取建议）

1. 领取某个模块任务时，先读本目录 `README.md` 确认任务范围；
2. **必读全局文件**：`00_总览.md`（项目背景、角色权限、非功能需求、待确认问题、里程碑）+ `01_前端总体设计.md`（技术选型、布局、设计规范、通用组件与状态规范）；
3. 再读对应的**模块文件**，如 `04_知识库.md`；
4. 任务完成后，如需修改需求内容，请同步更新主文档 `需求功能报告.md`，保持两份内容一致。

## 依赖关系

- 所有前端模块文件依赖 `01_前端总体设计.md` 的全局规范（色彩、组件、状态）；
- 所有模块文件依赖 `00_总览.md` 的项目上下文与非功能约束；
- `08_后端详细设计.md` 为设计草案，技术选型与字段定义待评审确认（见其 §11）。
- （新增）`09_应用评测.md` 与 `10_会话记录.md` 为新增模块文件，均依赖 `00_总览.md` 与 `01_前端总体设计.md`；`10_会话记录.md` 同时依赖 `03_智能客服.md`、`06_客服工单.md`。
