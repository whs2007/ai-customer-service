## 1. 功能概述

管理端内评估知识库回答质量：以评测集（黄金样本）为输入，批量执行问答并自动打分，输出可量化的评测报告；引用反馈与人工标注可回流为新的评测样本，形成评测闭环。

## 2. 路由与入口

- 路由：`/evaluation`；侧边栏“应用评测”（一级菜单，新增，侧边栏 7→9 项）。

## 3. 页面布局

```mermaid
graph TD
    A[页面标题: 应用评测] --> B[Tab: 评测集 | 评测任务]
    B --> C[评测集列表/创建/导入样本]
    B --> D[任务列表/创建任务]
    D --> E[任务报告页: 指标卡片 + 样本明细]
```

## 4. 元素明细

### 4.1 评测集列表

| 元素 | 说明 |
| --- | --- |
| 列表 | 名称、样本数、来源（手动/公开样例/反馈回流）、创建人、创建时间 |
| 操作 | 查看样本 / 导入样本 / 创建评测任务 / 删除（二次确认） |
| 空态 | “暂无评测集，请先创建” + “创建评测集”按钮 |

### 4.2 创建评测集与导入样本

| 元素 | 说明 |
| --- | --- |
| 创建弹窗 | 名称（必填，≤ 100 字，唯一）、描述（≤ 200 字） |
| 导入样本 | 支持手动逐条录入与 JSON 批量导入（`问题 / 期望答案 / 期望引用`）；首批内置 30 条公开样例模板 |
| 样例字段 | 问题（必填，≤ 500 字）、期望答案（必填）、期望引用 Chunk（可选，列表） |

### 4.3 评测任务列表

| 列 | 说明 |
| --- | --- |
| 任务信息 | 评测集名称、对话模型 Profile、状态（待执行/运行中/已完成/失败） |
| 进度 | 进度条（已完成/总数） |
| 结果 | 平均分（百分比）与分指标得分（回答准确性/问题相关性/语义准确性） |
| 操作 | 查看报告 / 重新运行（建议） / 删除 |

### 4.4 任务报告页

| 区域 | 说明 |
| --- | --- |
| 指标卡片 | 3 张卡片：回答准确性（先行实现）、问题相关性、语义准确性；展示分数与样本通过率 |
| 样本明细 | 表格：问题 / 模型回答 / 期望答案 / 引用 / 各项得分 / 通过标记（可人工调整通过状态） |
| 操作 | 导出报告（建议，CSV）；点击样本可展开引用详情 |

## 5. 指标定义

| 指标 | 口径 | 实现状态 |
| --- | --- | --- |
| 回答准确性 | 模型回答与期望答案的语义一致度，LLM-as-judge 打分 0–100 | 先行实现 |
| 问题相关性 | 回答与问题的相关程度，LLM-as-judge 打分 0–100 | 预留 |
| 语义准确性 | 回答事实与期望答案的一致性，LLM-as-judge 打分 0–100 | 预留 |

## 6. 状态设计

| 状态 | 表现 |
| --- | --- |
| 任务运行中 | 进度条 + 百分比；禁止重复提交运行 |
| 任务完成 | 报告可查看；平均分与通过率展示 |
| 任务失败 | 失败原因 + “重试”按钮 |
| 无样本 | 创建任务按钮禁用并提示“请先导入样本” |

## 7. 交互规则

- 创建评测任务时必须选择评测集与对话模型 Profile（默认取系统默认对话模型）；
- 任务运行异步执行（Celery），页面轮询或刷新获取进度；
- 报告页支持人工调整样本通过状态，调整结果影响通过率统计；
- 评测集删除需二次确认，级联删除样本（任务报告保留历史快照，建议）。

## 8. 数据回流（业务规则）

- 引用反馈（`03_智能客服.md` §4.4）与人工标注（`10_会话记录.md` §4.4）可标记为“纳入评测集”；
- 被标记的样本进入评测集候选，管理员确认后加入评测集（来源标注 feedback/annotation）；
- 评测结果与工作台看板联动（建议）：工作台展示最近一次评测平均分，见 `02_工作台.md`。

## 9. 验收要点

- 首批 30 条公开样例可导入并运行评测任务，报告指标与明细完整；
- 回答准确性打分可复现；人工调整通过状态后统计更新；
- 引用反馈/标注回流样本出现在评测集候选并可确认加入；
- 任务运行中/完成/失败状态与进度正确，无白屏。
