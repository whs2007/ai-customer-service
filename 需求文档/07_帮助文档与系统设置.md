### 1.2 页面布局

| 区域 | 说明 |
| --- | --- |
| 左侧目录 | 固定宽度约 200px；章节列表；当前章节高亮；可滚动 |

### 1.5 验收要点

- 目录与内容锚点跳转正确；图片渲染正常；
- 移动端目录可折叠（建议）。

## 2. 系统设置（规划，无原型截图）

侧边栏存在“系统设置”入口，原型未提供截图。建议按 Tab 组织：

| Tab | 内容建议 |
| --- | --- |
| 模型配置（变更） | 多套模型 Profile 管理（新增/编辑/删除/测试/设为默认），对话 / Embedding / 重排分开配置（见 §2.1） |
| Prompt 配置 | 系统人设、兜底话术、转人工判定规则（可编辑文本 + 恢复默认） |
| 客服规则（新增） | 转人工条件、工单优先级规则、人工客服账号分配、意图分类标签与分类规则配置 |
| 账号权限 | 用户管理（增删改、角色分配、重置密码） |
| 日志审计（变更） | 操作日志、对话日志、会话链路查看（trace）、保留策略 |
| 数据管理（新增） | 全量重建向量索引、备份/导出知识库、普通文本分块参数（500 字/重叠 50，可调） |

表单规范统一遵循 `01_前端总体设计.md`；危险操作（删除、重建索引）需二次确认。

### 2.1 模型配置（前后端自主切换）

**模型 Profile 列表**

| 列 | 说明 |
| --- | --- |
| 配置名称 | 如“智谱免费 GLM” |
| 提供商 | 智谱 GLM / OpenAI 兼容 / DeepSeek / 本地 Ollama |
| 模型 | 如 glm-4-flash |
| 用途（变更） | 对话 / Embedding / 重排（Rerank） |
| API Key | 脱敏展示（sk-***） |
| 默认 | 当前默认配置标记 |
| 状态 | 启用 / 停用 |
| 操作 | 编辑 / 测试连接 / 设为默认 / 删除 |

**新增/编辑弹窗字段**

| 字段 | 说明 |
| --- | --- |
| 配置名称 | 必填，≤ 50 字，唯一 |
| 提供商（变更） | 下拉：智谱 GLM / OpenAI 兼容 / DeepSeek / SiliconFlow / 本地 Ollama |
| 模型名 | 必填，如 glm-4-flash / bge-m3 |
| Base URL | 可选，默认使用提供商标准地址 |
| API Key | 新增必填；编辑时留空表示不修改 |
| 用途（变更） | 对话 / Embedding / 重排（Rerank） |
| 参数 | temperature（0–2）、top_p（0–1）、max_tokens（整数） |
| 启用开关 | 停用后不可被选择 |

**交互规则**

- “测试连接”按钮：调用后端校验配置，成功展示“连接成功，耗时 320ms”，失败展示具体错误；
- “设为默认”：默认 Profile 用于新对话与 Embedding；同一用途（对话/Embedding）同时只能有一个默认；
- （新增）“设为默认”：同一用途（对话/Embedding/重排）同时只能有一个默认；重排默认 Profile 用于“混合+重排”检索，未配置时自动降级为混合检索；
- （新增）默认重排配置建议：提供商 SiliconFlow，模型 `BAAI/bge-reranker-v2-m3`，Base URL `https://api.siliconflow.cn/v1`；API Key 由环境变量 `RERANK_API_KEY` 注入（存 `.env`，页面不回显）。
- 删除：默认 Profile 需先切换默认；删除需二次确认；
- 修改配置后提示“对新会话生效”；
- 对话页提供顶部模型快速切换下拉（**仅 admin 角色可见**，便于对比测试，默认使用系统默认模型）；
- 系统设置与模型配置整体仅 admin 角色可访问。

**验收要点**

- 多套模型 Profile 可增删改、测试连通、设为默认，API Key 全程脱敏；
- 切换默认模型后，新对话使用新模型，历史消息不受影响；
- 删除默认模型被拦截并有明确提示。
