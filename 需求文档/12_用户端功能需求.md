# 12 用户端功能需求

> 配套文档：`11_用户端与客服工作台设计方案.md`（总体架构）、`13_客服工作台与工单需求.md`
> 开发文档：`../开发文档/01_后端接口与数据模型设计.md`、`../开发文档/02_前端页面与组件设计.md`

## 1. 角色与入口

| 项 | 约定 |
|---|---|
| 角色 | 新增 `user`，与 admin/agent/viewer 并存 |
| 登录入口 | `/user/login`（独立页面，与管理端登录页分离） |
| 登录后首页 | `/user/chat`（在线咨询） |
| 使用场景 | 桌面 Web（移动端二期） |

登录成功后前端按角色跳转：

- `user` → `/user/chat`
- `agent` → `/workbench`
- `admin` → `/dashboard`

## 2. 注册与登录

### 2.1 自助注册

- 入口：用户端登录页提供“注册账号”链接；
- 字段：用户名（4~32 位，字母/数字/下划线/中文，唯一）、密码（8~64 位，含字母和数字）、确认密码、昵称（可选，默认取用户名）；
- 提交校验：两次密码一致、用户名可用性（失焦即时提示）；
- 注册成功即自动登录并进入在线咨询页；
- 防刷：注册接口按 IP + 用户名限流（每分钟 ≤ 5 次/IP），MVP 使用算术验证码（如 3+5=?），失败 3 次刷新验证码。

### 2.2 登录

- 账号密码登录，失败提示“用户名或密码错误”；
- 同一用户名连续失败 5 次锁定 15 分钟（提示剩余时间）；
- “记住我”勾选：控制 token 存储（localStorage 或 sessionStorage）；
- 登录失败/成功均不返回内部错误详情。

### 2.3 修改密码

- 个人中心提供“修改密码”：旧密码 + 新密码 + 确认新密码；
- 成功后使旧 token 全部失效（`token_version+1`），前端退出到登录页。

## 3. 在线咨询

### 3.1 页面布局（桌面）

```text
顶部导航：Logo | 在线咨询 | 我的工单 | 个人中心 | 用户名▾（退出登录）

咨询页：
  左栏（约 280px）：最近会话列表 + [＋ 新会话]
  右栏：对话区
    - 消息气泡：用户（右/蓝）、AI（左/灰）、人工客服（左/绿，带“人工”标签）、系统（居中灰字）
    - AI 消息可折叠“来源”展示（仅文件名）
    - 转人工后顶部显示状态条：“已转人工客服，您仍可继续留言，消息将保存供人工客服查看”
    - 底部输入框：Enter 发送、Shift+Enter 换行、长度 ≤ 500
```

### 3.2 会话规则

- 进入咨询页自动创建/恢复最近一个 `active` 会话（`channel=web_user`）；
- 同一用户同时最多 1 个 active 会话（超出时提示先关闭/等待当前会话）；
- 用户端**不选择知识库**：`kb_ids` 由后端按渠道配置解析（见开发文档 §4）；
- AI 回答带引用时，折叠展示“来源：文档名”，点击展开可看原文段落；
- 会话为空时显示引导语 + 常用问题快捷按钮（数据来自默认知识库热门条目或静态配置，MVP 静态配置即可）；
- SSE 断线自动重连，重连成功后补拉最新消息；网络异常时输入区上方提示“连接已断开，正在重连…”。

### 3.3 转人工

- 触发条件：用户消息命中投诉/转人工意图，或连续无法回答（沿用现有规则，具体阈值按系统设置）；
- 转人工后：输入框保持可用，AI 不再回复；新消息仅入库（role=user），并推送给客服端；
- 用户可看到“已为您转接人工客服，工单号 TK…，请稍候”系统消息；
- 人工客服回复后，用户端实时收到（SSE `message.new`），气泡带“人工客服”标识。

## 4. 我的工单

### 4.1 工单列表

- 只显示当前用户自己的工单；
- 列：工单号、状态（待处理/处理中/已关闭）、优先级（高/中/低）、最后更新时间；
- 分页（默认 10 条/页），支持按状态筛选。

### 4.2 工单详情

- 展示完整对话流（用户 / AI / 人工 / 系统），人工消息带客服昵称；
- 展示工单状态与流转时间（创建/认领/关闭）；
- 已关闭工单可评价一次（1~5 星 + 可选文字），评价后不可修改。

## 5. 个人中心

- 显示：用户名、昵称、角色、注册时间、最后登录时间；
- 操作：修改昵称（可选）、修改密码、退出登录；
- 帮助入口：跳转帮助页（静态说明：如何使用、转人工说明、隐私说明）。

## 6. 非功能需求

| 类别 | 要求 |
|---|---|
| 性能 | 首屏 < 2s；消息发送到回显 < 500ms；SSE 事件延迟 < 1s |
| 安全 | 行级权限（只能看自己数据）；密码 bcrypt；登录/注册限流；内容审核与 Prompt 注入防护；不返回内部字段（intent/trace/cited_chunk_ids） |
| 可用性 | 空状态/加载/错误态齐全；SSE 断线提示与重连；服务降级文案友好 |
| 兼容 | Chrome/Edge 最新两个大版本；分辨率 ≥ 1280 宽适配 |
| 审计 | 注册、改密、退出写审计日志；会话/工单访问留痕 |

## 7. 验收标准

1. 新用户可自助注册并自动登录；
2. 用户可发起对话，知识库命中的问题能正确回答并展示来源；
3. 无命中内容由 LLM 自然回复，不转人工；
4. 明确投诉/转人工后生成工单，状态流转正确；
5. 转人工后用户仍可留言，人工回复用户端实时可见；
6. 用户只能看到自己的会话与工单（越权访问返回 403）；
7. 断线重连后消息与状态一致（不丢、不重复）。
